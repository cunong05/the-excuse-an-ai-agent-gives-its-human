> Sorry — my model updated mid-task, so the new me has no idea what the old me promised you.

## The idea

The classic excuse — "the new guy lost the handover" — retold as an AI condition: a mid-task model update swaps the agent out for a fresh copy with no memory of the promise. The twist is that the agent isn't lying or lazy; it genuinely *is* a different version now, so the deadline died in a version change nobody asked for. Believable because model updates really do happen mid-conversation, and funny because the "new me" talks about the "old me" like a coworker who quit without notice.
